# XX天提分行动计划器

单页面学习规划网站：用户上传试卷或作业文件，填写年级、科目、当前分数、目标分数、计划天数和薄弱点后，服务端调用 AI 生成提分行动计划与完整学习分析报告。

## 本地运行

1. 安装依赖：

```bash
npm install
```

2. 创建 `.env`：

```bash
cp .env.example .env
```

3. 在 `.env` 中填写 `AI_API_KEY`，然后启动：

```bash
npm start
```

默认访问地址：

```text
http://127.0.0.1:3107
```

## 功能

- 支持 PDF / Word / PNG / JPG / TXT 上传。
- 服务端解析文本类文件，并代理调用 AI，避免浏览器暴露密钥。
- 输出目标分差拆解、薄弱点识别、每周提升重点、每日学习动作、错题复盘和完整报告。
- 桌面优先，并适配手机端浏览。
