# 教师备课器

面向中小学教师的单页 AI 备课工具。教师填写课堂信息、上传教材资料后，系统生成一份连续排版的完整教案，并可下载为可编辑的 Word 文档或与网页视觉一致的 PDF 报告。

专业教案 V2 包含：课程标准与课时定位、学情诊断、教学目标与达成证据、重难点突破策略、教学准备、完整教学过程、递进问题链、随堂分层练习、分层作业与反馈、板书设计、教学评价量规、课堂观察与应变预案、课后反思。

每个教学环节会分别给出任务目标、情境或任务、教师活动、学生活动、学习产出、支架与分层、设计意图、观察评价与时间分配。作业模块同时给出设计目的、预计用时和反馈方式，便于教师结合班级实际直接修改使用。

数学、物理、化学、生物、地理等学科的公式和符号统一使用 KaTeX 与 mhchem 渲染。生成教案后，可通过“AI优化建议”与模型连续对话，模型会根据当前完整教案和教师要求更新右侧内容。

## 成品启动

首次运行：

```powershell
npm install
npm run build
npm start
```

浏览器访问 `http://localhost:8787`。

## 开发模式

打开两个终端，分别运行：

```powershell
npm run dev
```

```powershell
npm start
```

浏览器访问 `http://localhost:5173`。

## AI 配置

普通工作台不显示 AI 配置入口。管理员可直接访问 `http://localhost:8787/#settings` 进入独立配置页。

1. 打开独立 AI 配置页。
2. 填写 API 地址、模型名称和 API Key。
3. 点击“测试连接”，成功后保存。
4. 返回主界面生成备课方案。
5. 检查文档预览后，下载 `.docx` 或 `.pdf` 教案，也可以继续使用 AI 对话优化。

支持 OpenAI Chat Completions API，以及兼容该接口格式的模型服务。配置保存在当前浏览器的 `localStorage`，不会写入源码。

没有配置 API Key 时，系统会返回一份明确标记的本地演示方案，便于先体验完整交互。

## 导出说明

- Word：普通正文保持可编辑；学科公式会渲染为透明高清公式图嵌入对应段落，避免在不同电脑上出现公式字体或转义符问题。
- PDF：克隆当前完整桌面报告并按章节、教学环节和卡片边界智能分页，保留网页中的颜色、层级和公式效果。
- PDF 为高分辨率网页报告成品，适合打印与分享，不用于逐字编辑。

## 资料支持

- PDF：服务端提取文字后送入模型。
- DOCX：服务端提取正文后送入模型。
- PNG / JPG：作为视觉输入发送给支持图片理解的模型。
- TXT / Markdown / CSV / JSON：直接读取文本。
- 单次上传资料总大小不超过 24MB。
