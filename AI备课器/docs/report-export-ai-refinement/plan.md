# 专业报告导出、学科公式与 AI 对话优化

## 问题与动机

当前教案已经支持多轮对话优化、公式渲染和 Word/PDF 导出，但优化链路仍把 13 个专业模块视为不可变结构。服务端会补回缺失字段，网页和 Word 也按固定模块渲染，导致教师无法通过提示词新增、删除、改名或重排模块，也不能真正调整整份教案的排版和图示。

## 范围

- 保留 13 个专业模块作为首次生成教案的默认模板。
- 将对话优化结果升级为动态教案文档，支持封面、标题、正文、模块、顺序和页尾内容修改。
- 支持段落、列表、键值信息、卡片、时间线、表格、图片和 SVG 图示等通用内容块。
- 支持模块级单栏、双栏、三栏、网格、时间线、板书、表格和图库排版。
- 网页预览、复制正文、Word 和 PDF 使用同一份动态教案内容。
- 所有动态文本继续使用统一公式和安全 SVG 渲染管线。
- PDF 导出兼容浏览器 CSS Color 4 计算值，不能因 `color()` 等 html2canvas 不支持的颜色函数中断下载。
- 网页预览中的安全 SVG 在 Word 中转换为高清 PNG 嵌入，确保 WPS 可见；转换失败时才回退为可访问说明。
- 对话中未限定媒介的“图、图示、结构图、流程图”等要求默认生成安全自包含 SVG。
- SVG 可见文字统一进入学科公式归一化管线，覆盖数学、物理、化学、生物、地理等学科，不允许把 LaTeX 控制命令直接显示给教师。
- 板书模块只保留页面提供的一层黑板容器；内部 SVG 使用透明背景，不重复绘制整画布背景或装饰性外框。

## 非目标

- 不执行模型返回的任意 HTML、JavaScript 或 CSS。
- 不提供自由代码编辑器或任意网页嵌入能力。
- 不实现多人协作、账号系统或跨网页刷新的聊天记录。
- 不要求首次生成接口放弃专业教案默认模板。

## 设计边界与约束

- 教师最后一条明确要求具有最高优先级，可以新增、删除、改名、合并、拆分或重排模块。
- 未被要求修改的内容应保留，但不得因兼容旧模型而强制补回教师已要求删除的模块。
- 动态排版只使用受控布局和内容块白名单，避免脚本注入和不可预测的页面样式。
- 图片地址只接受安全的 HTTPS 地址或受支持的图片 Data URL；新增教学示意图优先使用安全自包含 SVG。
- 教师明确要求照片、真实图片、插画、PNG、JPG、位图、网络图片或图片地址时，按明确媒介执行，不套用“图默认 SVG”规则。
- 动态教学环节仍应保持课时总时长一致；若教师明确删除或替换整个教学过程，不得重新生成固定教学过程模块。
- PDF 继续从当前网页教案生成，并在快照前把不兼容颜色值固化为 html2canvas 可解析的颜色；Word 根据当前动态模块顺序输出可编辑文本、表格、公式和 SVG 对应图形图片。
- SVG 安全白名单只负责安全性；`text` 和 `tspan` 的教学可读性由共享学科文本转换层负责。规则按 LaTeX、上下标、化学式和 Unicode 符号语法扩展，不按具体知识点硬编码。
- `blackboard` 布局内覆盖画布的背景矩形和包围整幅内容的装饰框在渲染与 Word 栅格化前统一移除；坐标轴、几何图、关系线和内容分栏必须保留。

## 高层实施计划

1. 建立动态教案文档、模块和内容块的共享归一化模型。
2. 将旧版 13 模块教案转换为动态文档后交给 AI 优化。
3. 调整优化提示词和接口，取消固定字段回填并保留显式模块增删结果。
4. 增加动态网页渲染、正文复制和 Word 导出。
5. 补充接口、数据模型、Word 和真实浏览器回归验证。
6. 增加 PDF 颜色兼容层与 Word SVG 栅格化层，统一网页、PDF、Word 的图形内容。
7. 增加共享 SVG 教学文字转换与板书去装饰层，并让网页和 Word 使用同一规范化结果。

## 验证

- 提示词可以删除旧模块、添加自定义模块、修改模块标题并改变顺序。
- 提示词可以修改封面标题、正文、列表、表格、卡片、SVG 图示和模块布局。
- 页面不显示被删除的模块，也不会因默认值合并而重新出现。
- 复制正文、Word 与 PDF 的模块标题和顺序与网页一致。
- 动态内容中的公式与 SVG 正常渲染，危险 SVG 内容继续被过滤。
- PDF 在动态主题下可正常下载，不出现 `unsupported color function`。
- DOCX 包含 SVG 对应的 PNG 媒体和 Drawing 引用，图注与网页一致。
- 对话中的普通“图”要求进入 SVG 内容块，明确指定照片或位图时不强制转换。
- 桌面端和移动端无横向溢出，控制台无错误。
- 数学、物理、化学、生物和地理 SVG 样例分别显示 `√`、`≥`、`⇒`、希腊字母、Unicode 上下标、规范化学式和经纬度，不残留 `\sqrt`、`\frac`、`\ce` 等控制命令。
- 板书 SVG 的全画布背景和整幅装饰框被移除，教学文字、坐标轴、几何图和局部分栏仍存在；桌面和手机端 SVG 均占满可用内容宽度。

## 回滚

- 停用动态 `sections` 分支即可恢复固定 13 模块页面和 Word 输出。
- `/api/optimize` 可回退到旧版 `mergePlan`，首次生成和本地演示教案不受影响。
- 如浏览器兼容层异常，可仅回滚 PDF 克隆颜色固化；如 SVG 栅格化异常，Word 会自动回退为图示说明而不中断下载。
