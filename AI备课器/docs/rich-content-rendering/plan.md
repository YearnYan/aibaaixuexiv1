# 全学科公式容错与 SVG 安全渲染

## 问题与动机

AI 可能输出未闭合公式、未加定界符公式、非法中文 LaTeX 命令、重复箭头以及原始或转义的 SVG 源码。现有渲染器只处理完整标准定界符，导致板书和其他模块泄露控制命令，SVG 也会被当成普通文本。

## 范围

- 建立供全部教案模块复用的统一富内容解析入口。
- 修复不完整公式定界符、中文上下标命令和常见蕴含符号。
- 自动识别未加定界符但具备明确语法特征的数学、物理、化学、生物、地理等学科表达。
- 安全识别并直接渲染原始、代码围栏和 HTML 转义形式的 SVG。
- 保证网页、PDF、Word 和板书清理流程不会再直接暴露 SVG 源码或异常 LaTeX 控制命令。
- 增加生成端格式约束、跨学科回归测试和真实浏览器验收。

## 非目标

- 不按具体知识点维护公式替换表。
- 不允许 SVG 脚本、外链资源、嵌入 HTML 或任意 CSS。
- 不把任意普通英文或数字文本强制判断为公式。
- 不改变现有 13 个教案模块和业务数据结构。

## 实施计划

1. 扩展科学文本解析器，增加标准化、缺失定界符恢复和裸公式识别。
2. 增加 SVG 提取、元素与属性白名单净化、可访问描述和安全回退。
3. 将网页 RichText、板书清理和 Word 导出接入统一入口。
4. 增强模型生成提示，禁止非法中文命令、未闭合公式和危险 SVG。
5. 建立跨学科公式及 SVG 安全测试矩阵，执行构建和浏览器验收。

## 验收标准

- 用户示例中的 `\\implies`、`F_{\\向上}`、未闭合 `\\(` 均不再原样显示。
- 数学、物理、化学、生物、地理常用表达能够渲染或回退为可读、可编辑文本。
- 三种 SVG 输入形式均生成真实 `<svg>` 节点，而非显示源码。
- script、foreignObject、事件属性、外链和危险 URL 均被移除。
- Word 中公式继续使用 Office Math，SVG 不以源代码形式写入正文。
- 自动化测试、生产构建和真实浏览器控制台检查全部通过。

## 回滚方案

- RichText 可退回仅调用 `splitScientificText` 的公式渲染路径。
- SVG 段可统一回退为可访问文字描述，不影响其他教案内容。
- 生成提示增强可独立回滚，不改变接口和教案 JSON 结构。
