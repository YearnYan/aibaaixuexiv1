# AI 得分点拆解网站实施计划

## 问题与动机

学生常常“知道答案”却没有覆盖评分标准中的结论、依据、步骤、关键词或格式要求。网站需要把题目资料和评分标准拆成可观察的得分点，并识别题目文件或独立答案文件中的学生作答：有作答时逐项诊断，没有作答时仍提供六维解题指导。

## 范围

- 提供与 `UI.png` 一致的单页得分点分析工作台。
- 支持上传 PDF、Word、PNG、JPG、纯文本和 Markdown 题目资料。
- 支持识别题目图片内的手写步骤、填写内容或答案，也支持可选的独立学生答案文件。
- 六个固定维度均提供可展开的评分观察、针对性分析和提分动作。
- 未检测到作答时进入解题指导模式，不显示误导性的零分结论。
- 未检测到作答时，六维中的评分观察、解题指导、解题建议同时保留通用方法并追加本题具体对象、数据、条件、公式或图表关系。
- 在网页中统一渲染数学、物理、化学、生物、地理等学科的标准 LaTeX 公式与学科符号，不使用按科目枚举的局部替换表。
- 支持下载完整报告 PDF 和 Word；导出内容与网页报告字段一致，Word 正文保持可编辑。
- 调用真实 AI 接口生成结构化得分报告。
- 提供独立 AI 配置页，支持 OpenAI Responses API 与兼容 Chat Completions API。
- 服务端持久化并加密保存 AI 密钥，浏览器只接收掩码。
- 适配桌面和移动设备。

## 非目标

- 不建设用户、班级、作业发布或多租户系统。
- 不替代教师对开放性答案的最终判断。
- 不生成完整参考答案供学生直接抄写。
- 不在本次范围内提供云端部署、域名或第三方账号开通。

## 设计边界与约束

- 主体布局延续参考图；六维结果区采用阅卷诊断单语义，禁止使用票券缺口、撕口虚线和商品标签式状态胶囊。
- 题目资料应优先包含教师认可的参考答案和评分标准；缺失时 AI 可推断，但必须标记需要教师复核。
- 单文件最大 15 MB，每次最多上传题目资料和学生答案各一份。
- 分析输出必须通过服务端 Schema 校验和分值归一化，不能直接信任模型文本。
- “是否存在学生作答”由题目文件与答案文件共同决定，不能只依据是否上传独立答案文件。
- 报告文案必须由 `guidance`、`needs_improvement`、`full_score` 三种结果状态驱动；满分状态不得出现“待补充、修改、未识别到有效表达”等冲突文案。
- 报告文本中的行内公式统一使用 `\(...\)`，独立公式使用 `\[...\]`，化学式和化学方程式使用 `\ce{...}`；服务端拒绝未闭合、不可解析或未包裹的 LaTeX 命令。
- 公式渲染必须关闭可信 HTML 扩展，AI 文本始终按纯文本处理，避免公式内容绕过页面转义。
- PDF 中题目、总分概览、单个得分维度、整体建议和复核说明均为不可拆分页块；当前页空间不足时整体移动到下一页。
- Word 中叙述文字使用原生可编辑段落，公式使用由同一 LaTeX 源生成的高分辨率图像，确保 Word 与 WPS 中稳定显示。
- API 密钥不得写入前端资源、日志、错误响应或公开接口。
- 生产环境的配置接口必须由 `ADMIN_PASSWORD` 保护；未设置时禁止远程配置。

## 高层实施计划

1. 搭建 Express 服务、静态页面与安全中间件。
2. 实现 AI 配置加密存储、掩码读取和连接测试。
3. 实现文件校验、题面作答识别、两类 AI 协议适配、结构化输出校验与分值归一化。
4. 实现六维阅卷诊断单、展开解析和无作答指导模式。
5. 增加单元/接口测试，并通过 Playwright 验证桌面和移动端。
6. 补充运行、配置和使用说明。
7. 增加学科公式校验与浏览器渲染层，覆盖数学公式、物理量与单位、化学式及方程式、生物遗传表达和地理计算表达。
8. 增加 PDF/Word 报告导出层，并验证分页、公式显示、可编辑文本和移动端操作。

## 验证

- `npm test` 在 60 秒内完成并覆盖配置、结果归一化和主要 API 分支。
- `npm run check` 完成 JavaScript 语法检查。
- 使用模拟 AI 响应跑通上传、分析和结果渲染。
- 分别验证题面含作答、独立答案文件、完全无作答三种模式。
- 验证每个维度可通过鼠标和键盘展开，且内容与当前维度对应。
- 使用 Playwright 在 `1536×1024` 与移动视口截图核对布局，无溢出或遮挡。
- 配置接口不返回完整密钥，错误日志不包含请求中的密钥或文件正文。
- 使用跨学科公式样例验证服务端 LaTeX 校验和网页渲染，浏览器控制台不得出现公式解析错误。
- 下载实际 PDF 并逐页渲染成图片检查，不得出现得分维度或建议块被页尾切割。
- 下载实际 DOCX，检查正文可提取、结构完整、公式媒体存在，并优先使用本机 WPS 做视觉复核。

## 回滚

- 删除新增服务文件即可回到仅含参考图的初始状态，不涉及外部数据迁移。
- AI 配置存储位于 `.data/`，停止服务并移除该目录即可清除本地配置。
- 若兼容接口不稳定，可在配置页切回 OpenAI Responses API，不影响前端或结果模型。
- 若新模型字段缺失，服务端使用六维默认指导补齐；回滚前端展开区不会影响原有分值字段。
- 若导出依赖异常，可移除报告操作栏和供应商静态资源路由，不影响上传与分析主流程。
- 若公式渲染器异常，可回滚到纯文本展示；服务端仍保留规范 LaTeX 源，避免数据丢失。
