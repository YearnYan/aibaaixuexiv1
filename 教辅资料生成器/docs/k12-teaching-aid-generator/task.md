## 阻塞因素和未决风险

- 生成规则确认依赖所选规则接口的 `/chat/completions` 文本/多模态通道，若规则网关不支持图片输入或 JSON 输出会返回规则生成失败。
- PDF 页面截图只在规则确认阶段作为内容识别证据；极端扫描件仍可能需要用户填写更明确的拆分需求或补充清晰教材截图。
- 特殊字体或扫描型 PDF 可能出现文本抽取乱码；规则确认已要求优先依赖页面截图、知识库图片和标题线索，但仍受规则模型多模态识别能力影响。
- 批量带参考图生成不再默认走参考图编辑接口，参考图风格说明依赖规则确认模型稳定输出；正式生图阶段不再追加第二次视觉分析。
- 兼容网关若完全不转发 SSE partial/completed，只在明确 400/422 拒绝流式参数时安全回退；结果未知时会在单次操作后报错，不再用三轮重生成换取偶发成功。
- 后台自动规则确认依赖有效的规则接口池，因此即使用户不再看到规则按钮，正式生图前仍必须在后台配置规则模型通道。
- 知识库蓝图抽取依赖规则模型的文本/多模态理解能力；当规则模型无法可靠读取扫描件截图时，服务端会保留不确定说明并禁止编造，但仍可能需要用户补充更清晰资料。
- `public/generated/` 是本地运行产物目录，长期运行时需要定期清理或迁移到对象存储。
- `data/ai-config.json` 是本地密钥配置文件，若部署到公网应限制管理员账号与后台访问。
- `data/app-state.json` 将包含账号、会话、积分、卡密和流水，本地文件并发写入需要串行化保存，且必须被版本控制忽略。
- 当前本地 JSON 状态适合单进程部署；多实例部署需要换成数据库或集中式存储。
- Cloudflare Workers KV 是最终一致存储；本轮短状态事务队列只保证同一 Worker 实例内写入有序。若后续要求跨边缘节点强一致的积分与取消语义，需要迁移到 Durable Objects 或其他强一致存储。
