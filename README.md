# 艾爸AI学习

艾爸AI学习是面向 K12 学习场景的品牌主站与工具矩阵，包含统一账号、积分兑换、独立积分管理后台、独立 AI 配置后台，以及 21 个可按需启动的学习与教学工具。

## 本地运行

```powershell
npm run setup
npm run build
npm start
```

启动后访问：

- 品牌主站：`http://127.0.0.1:4173`
- 积分管理后台：`http://127.0.0.1:4173/points-admin.html`
- AI 配置后台：`http://127.0.0.1:4173/ai-config-admin.html`

AI 配置后台登录后可先维护“全局 AI”，再逐个为 21 个子站选择跟随全局、独立接口或停用；已有的教辅资料生成器文本与生图接口池继续保留。

主站会启动账号与积分后端；用户点击工具卡片时，对应子站才会按需启动。各子站继续使用自己的原业务代码和 API，不合并接口命名空间。

## 品牌系统

- 品牌色：纸白、暖阳金、砖红、墨棕、青绿
- 首屏主题：学习列车驶入知识站台
- 首屏背景：AI 直接生成的无人物位图
- 全站主题源：`brand/aiba-brand.css`
- 同步主题：`npm run sync:brand`

## 验证

```powershell
npm run check
```

大型变更的计划、模型、任务状态和变更记录位于 `docs/aiba-brand-refresh/`。
