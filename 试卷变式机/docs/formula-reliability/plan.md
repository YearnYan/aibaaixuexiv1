# 公式生成可靠性计划

## 问题与动机

模型生成的题干、答案或解析可能随机漏写、混用或错序使用公式定界符。旧链路把任一字段的格式错误直接升级为整卷失败，导致用户即使已经获得绝大多数合格题目，也无法拿到结果。

## 范围

- 仅覆盖“试卷变式机”的 Node 与 Worker 生成链。
- 统一处理题干、选项、答案、解析和标题中的公式定界符问题。
- 增加确定性规范化、坏字段定点返修和最终安全降级。
- 记录返修数量、成功路径和降级路径，便于线上追踪。

## 非目标

- 不修改其他子网站。
- 不改变题量、题目顺序、难度、变式系数、知识点或考点。
- 不改变积分、身份验证、上传文件和题图生成契约。
- 不承诺自动纠正模型的学科语义或计算错误。

## 设计边界与约束

- 模型输出视为不可信输入，局部公式格式错误不得阻断整卷。
- AI 返修只能接触已定位的坏字段，不能接触其他字段。
- 最终降级只能移除孤立定界符，必须完整保留正文和 LaTeX 源码。
- 返修后必须重建答案汇总，并再次执行完整性校验。

## 高层实施计划

1. 用结构化扫描器识别混用、漏闭合、孤立闭合、错序和嵌套。
2. 对坏字段最多执行两次低温定点返修。
3. 返修未收敛时移除孤立定界符，交由现有隐式 LaTeX 渲染器展示。
4. 在 Node 常规生成、Node 上传变式、Worker 常规生成和 Worker 上传变式中统一接入。
5. 通过样例、失败注入、排列穷举、全量测试和生产健康检查验证。

## 验证

- 学术内容专项测试覆盖线上 `questions[0].items[5/6].explanation` 场景。
- 穷举六个定界符的全部 4096 种排列，验证正文不丢失且终态成对。
- `npm test` 全量通过，Worker 构建通过。
- 服务器端测试通过，服务重启后本机和公网健康接口正常。

- 恢复部署前备份的目标文件并重启 `teacher-ai-platform`。
- Git 回滚本功能提交时只回滚“试卷变式机”目录内的本次文件。
