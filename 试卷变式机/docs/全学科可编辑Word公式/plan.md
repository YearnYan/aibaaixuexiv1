# 全学科可编辑 Word 公式导出计划

## 问题陈述和动机

“试卷变式机”当前把 HTML 内容包装成旧式 `.doc` 文件。公式虽然以 MathML
写入 HTML，但 Word/WPS 对这种容器的导入行为不一致，不能保证数学、物理、
化学、生物、地理等学科公式成为可编辑的原生公式对象。

本变更把 Word 导出升级为真正的 Office Open XML `.docx` 文件。LaTeX 与
mhchem 先由 KaTeX 生成规范 MathML，再转换为 Word 原生 OMML；普通学科符号、
上下标和正文保留为可编辑文本，禁止把公式栅格化为图片。

## 范围

- 仅修改“试卷变式机”的 Word 导出实现、直接依赖、构建与回归测试。
- 覆盖题目标题、题干、选项、答案和解析中的全部公式与学科符号。
- 支持数学、物理、化学、生物、地理及其他遵循统一 LaTeX 契约的学科内容。
- 保留题目自身的必要图形；题图可以是图片，但公式本体不得是图片。

## 非目标

- 不修改网页公式展示、PDF 导出、AI 生成提示词、HTTP 接口或计费流程。
- 不修改题图生成和题图内容。
- 不修改其他子网站、统一平台或部署配置。
- 不兼容继续生成旧式 HTML `.doc`；下载文件统一升级为 `.docx`。

## 设计边界和约束

- 文档必须是可解包的标准 DOCX ZIP 包。
- 公式必须写入 `word/document.xml` 的 OMML 节点，禁止使用公式截图、Canvas
  或 SVG 代替。
- 普通文本必须写入 Word 文本运行；文本上下标使用 Word 原生字符格式。
- LaTeX/mhchem 转换失败时终止导出并给出明确错误，不得静默输出乱码或线性降级。
- 文件名、XML、关系和图片数据必须经过安全转义和完整性校验。

## 高层实施计划

1. 把学术文本拆分为普通文本、行内公式和独立公式令牌。
2. 使用 KaTeX/mhchem 将公式转换为 MathML，再转换为 OMML。
3. 构建标准 DOCX 包、样式、关系、正文和必要题图。
4. 替换旧式 `.doc` 下载逻辑，保留现有用户操作入口。
5. 增加五大学科、复杂公式、正文上下标、DOCX 包结构和禁止公式图片化测试。
6. 生成真实 DOCX，解包检查 OMML，并通过 WPS/兼容渲染工具逐页验收。

## 验证

- 单元测试覆盖数学、物理、化学、生物、地理代表性公式和复杂结构。
- DOCX 解包后必须存在 OMML，且公式数量与输入令牌数量一致。
- `word/media/` 只能保存题图；不得出现公式图片关系或公式图片占位。
- Word 文本提取结果必须保留题干、选项、答案和解析。
- 前端与 Worker 构建通过，现有全量测试无回归。
- 实际 DOCX 可由 WPS/LibreOffice 打开并完成逐页渲染检查。

## 回滚

回滚本功能提交并恢复原 `exportToWord`、依赖清单和构建产物即可。该变更不涉及
数据迁移、服务端持久化或 HTTP 契约，回滚不会影响已有试卷数据。
