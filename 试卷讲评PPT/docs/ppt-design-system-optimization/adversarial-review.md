# 对抗式设计审查

## 总体评分

**8.9 / 10（优秀）**

- 哲学一致性：9.1 / 10。应用外壳始终围绕教师批注与试卷到课堂的真实链路，PPT 内页没有退化为网页卡片墙。
- 视觉层级：9.2 / 10。题号、题型、题干、作答、解题路径和知识锚点形成稳定阅读顺序。
- 细节执行：8.8 / 10。间距、分隔、色彩、裁切和固定画布统一；短题保留必要留白。
- 功能性：9.3 / 10。三类版式、答案开关、目录、全屏、窄屏缩放和导出互不冲突。
- 创新性：8.3 / 10。批注线、纸张语汇和模块编号具有场景辨识度，但仍以课堂清晰度为先。

## 对抗用例与结论

1. **极短选择题**：不添加虚构教学提示填空；左侧保留呼吸区，右侧解题路径拉满纵向节奏。
2. **带图题**：图形使用 `contain` 完整显示；说明与来源降为 caption，不争夺图形主角位置。
3. **小定位框与边缘定位框**：扩张后仍在 0–1 边界内；小框最小上下文约 34%×28%，不再扩到接近整页。
4. **极宽裁切**：1000×100 源区域输出 1800×180，长宽比保持 10:1，无拉伸。
5. **连续步骤长解析**：能识别“第一步…最后说明”，最多保留 5 个有序步骤；压测页使用 `compact` 而非直接缩到不可读字号。
6. **移动端 390px**：PPT 使用固定 1040×585 逻辑画布等比缩放，页面横向溢出为 0，操作按钮高度 46–48px。
7. **移动端导出**：不抓取低分辨率缩略图；直接抓固定逻辑画布并得到 1600×900 JPEG，临时节点增量为 0。
8. **答案泄露**：关闭时正确项标记为 0；开启时恰好 1 个正确项与 1 个勾选图标。
9. **可访问性**：上传区为语义分组，选择/拍照为独立按钮；无重复 ID，键盘焦点轮廓为 3px。
10. **独立部署**：缺少共享导航脚本时先校验 Content-Type 并静默降级，控制台 0 错误、0 警告。

## 已修复的致命/重要问题

- ⚠️ 移动端 PPT 内部按桌面像素重排导致内容叠压：改为固定逻辑画布等比缩放。
- ⚠️ 长解析只检查外层高度，内部解析区仍可能被裁掉：增加关键容器逐层溢出检测。
- ⚡ 小图形定位框被统一放大 2.6 倍：改为按面积与长宽比自适应留白。
- ⚡ 极宽/极高裁切被最小宽高分别拉伸：改为单一比例缩放。
- ⚡ 上传区嵌套交互语义错误：改为分组 + 两个真实按钮。
- ⚡ 共享导航缺失时把 HTML 当脚本执行：改为 HEAD 与 Content-Type 守卫。

## 剩余风险

- 当前环境未配置 `OPENAI_API_KEY`，因此未执行真实 AI 识别与完整 `.pptx` 文件写出；已验证前端数据契约、三类模拟课件、截图导出核心链路和 1600×900 输出。
- 超出压测样例很多的异常长题仍可能进入 `clamped` 状态；此时优先保持字号并截断低优先级尾部，而不是继续缩小到不可读。
