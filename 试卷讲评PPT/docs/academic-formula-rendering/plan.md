# 跨学科公式渲染与课件视觉重构计划

## 背景与问题

当前 AI 提示词明确禁止 LaTeX，导致数学根式、幂、三角函数等以 `sqrt(3)`、`x^2`、`sin(theta)` 的程序表达式进入课件。普通 HTML 转义随后把这些字符串原样显示并截图进 PPT。相同问题也会影响物理量、化学反应式、生物遗传公式、地理角度与比例尺。现有画布同时存在粗重顶栏、模块编号、卡片边框和信息密度偏高的问题。

## 目标与范围

- 建立数学、物理、化学、生物、地理及其他学科通用的 LaTeX 内容契约。
- 使用 MathJax SVG 渲染题干、选项、答案、解析和知识点中的公式。
- 为历史或不合规 AI 输出提供程序表达式到 LaTeX 的兼容规范化。
- 让内容测量、预览切换与 PPT 截图导出等待公式渲染完成。
- 重构 16:9 课件视觉层级，提升课堂投屏可读性并降低 UI 面板感。

## 非目标

- 不手工穷举每一道题或依赖固定题库。
- 不改变试卷文件解析、图形定位和图像裁切算法。
- 不把公式重新编辑成 PowerPoint 原生公式对象；导出继续使用高清课件画布截图。
- 不自动修改原题事实、符号含义或学科结论。

## 设计边界与约束

- AI 返回 JSON 必须合法，LaTeX 反斜杠必须正确转义。
- 行内公式使用 `\(...\)`，独立公式使用 `\[...\]`，化学式与反应式使用 `\ce{...}`。
- 兼容层只转换具有明确公式特征的片段，普通中文、英文与题目叙述不得误转。
- 所有动态文本先转义再生成公式标记，禁止通过公式渲染引入 HTML。
- MathJax 失败时保留原始内容，不阻塞课件其他功能；导出前等待有上限。
- 课件视觉保持 16:9、1600×900 导出和现有纸白、墨绿、讲评红品牌关系。

## 高层实施计划

1. 定义跨学科 LaTeX 输出规则与规范化接口。
2. 实现纯 JavaScript 学科公式模块并建立跨学科测试样本。
3. 在 AI 响应规范化、HTML 生成、MathJax 排版与导出等待中接入模块。
4. 重构课件头部、内容网格、选项、讲解步骤、题图和考点样式。
5. 使用浏览器夹具逐科验证公式、布局、溢出和导出截图。

## 验证

- 数学：根式、分式、幂、三角函数、向量、矩阵、积分与几何符号可渲染。
- 物理：上下标、矢量、希腊字母、单位和科学计数法可渲染。
- 化学：分子式、离子、电荷、状态、反应箭头和可逆反应可渲染。
- 生物：遗传平衡式、基因型、DNA/RNA 序列和统计符号可渲染。
- 地理：经纬度、角度、比例尺、太阳高度和单位可渲染。
- 页面中不存在可见的 `sqrt(`、`sin(theta)`、裸 `^2` 或 `2*` 等遗留表达。
- 每科夹具均无公式源码泄露、无内容溢出，导出画布为 1600×900，控制台无错误。

## 公式恢复扩展

### 问题与动机

现有公式重试只追加通用提示并重新识别整批试卷，没有携带具体题号、字段路径、错误片段和上一版结构化内容。模型无法精确定位错误，还可能改写已经正确的题干、选项或题序；第二次响应仍含裸 `\frac` 等不完整命令时，整批生成被浏览器弹窗终止。

### 范围

- 对显式 LaTeX 的分隔符、花括号和必需参数做结构诊断。
- 将公式问题定位到题目索引和字段路径，只请求 AI 返回对应字段补丁。
- 使用原题上下文、原页图和零温度执行多轮定向修复，每轮合并后重新全量校验。
- 将生成失败改为页面内可恢复状态，保留已上传文件并允许继续修复。

### 非目标

- 不放宽公式质量闸门，不把不完整公式转成近似文本。
- 不使用本地猜测补写分子、分母、单位或学科结论。
- 不允许修复响应改动题序、题图定位或未被诊断的字段。

### 设计边界与约束

- 只有全部题目、全部字段通过结构校验和遗留表达式校验后，才进入预览与 PPT 导出。
- 单轮修复必须覆盖本轮全部问题字段；缺字段、越权字段、非法 JSON 或仍不合格的公式均视为本轮失败。
- 自动修复次数有明确上限；上游持续失败时保留上传上下文并提供“继续修复”，不得展示未校验内容。

### 高层实施计划

1. 扩展 `AcademicMath` 结构诊断，输出可机器处理的问题对象。
2. 新增纯 JavaScript 字段补丁契约模块，负责问题收集、提示构建、响应解析与受限合并。
3. 将整批语义重识别替换为字段级自动修复循环。
4. 重构生成状态卡的处理中、修复中和可恢复错误三态。
5. 通过单元测试、模拟 AI 响应和桌面/移动浏览器完成对抗验收。

### 验证与回滚

- 验证裸 `\frac`、缺参数 `\frac{1}`、未闭合分隔符和花括号均会被定位并进入字段修复。
- 验证补丁只能修改被诊断字段，其他题目事实、选项正确性、题图与顺序保持不变。
- 验证连续无效补丁不会进入预览，并可在原页面继续修复。
- 回滚时恢复本次变更前的 `academic-math.js`、应用脚本、首页和样式文件，并移除字段补丁模块及对应测试；不涉及持久化数据。
