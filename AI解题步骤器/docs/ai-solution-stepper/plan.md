# AI 解题步骤器实施计划

## 问题与动机

用户需要的不是学生作答训练系统，而是 AI 解题指导生成器。工具读取题目后一次性生成四个步骤的具体内容，让用户直接查看每一步应如何理解、选择方法、计算和检验，不要求用户填写步骤答案。

## 范围

- 单页解题工作台：自动识别的学科、年级、题目文件与分步结果。
- 支持 PDF、DOCX、PNG、JPG、WEBP 和纯文本题目材料。
- AI 自动生成题目摘要、四步目标、每步具体指导内容、三级补充指导和第 5 个“完整答案”模块。
- 四步内容在一次生成后全部可查看，用户只通过步骤标题切换展开内容。
- 结果区提供 PDF 与 Word 完整报告下载，两个文件与网页使用同一份内容和公式渲染源。
- 数学、物理、化学、生物、地理等学科的公式、单位、化学式与专业符号统一使用 Markdown + LaTeX 契约。
- 独立 AI 配置页：OpenAI 兼容接口地址、模型、密钥、温度、超时与连通性测试。
- 桌面端沿用参考图的左右分栏、黑白排版、步骤状态与浅黄色展开区；强调色改为低饱和墨蓝，移动端改为纵向工作流。

## 非目标

- 不实现账号、班级、作业发布、多人协作和长期学习档案。
- 不实现支付、配额计费和多租户管理。
- 不实现学生步骤作答、AI 判分、提示申请、步骤锁定和同类题验证。
- 不把 API 密钥发送到浏览器。
- 不在用户主页面展示配置入口、模型名称、服务商或配置状态；配置页仅允许管理员通过直达地址访问。

## 设计边界与约束

- AI 密钥仅由服务端读取，并使用本地密钥进行 AES-256-GCM 加密存储。
- 未配置管理密码时，仅允许本机访问配置接口；公开部署必须设置 `ADMIN_PASSWORD`。
- 上传文件限制为 10 MB，提取文本限制为 30,000 字符，防止请求失控。
- 只读结果会话保存在服务端内存并设置过期时间；服务重启后需要重新生成路径。
- AI 返回内容必须经过结构校验，失败时返回可操作的中文错误，不展示内部堆栈或密钥。
- 每个步骤必须包含可直接阅读的具体指导和三级补充说明；第 5 个模块展示自包含、可直接用于教学核对的完整答案。
- 所有公式节点必须通过 KaTeX 严格编译；正文拒绝乱码、私用字符、裸数学符号、裸上下标、裸科学单位和未用 LaTeX 包裹的公式。
- 化学表达使用 `\ce{}`，量与单位使用 `\mathrm{}`，公式只允许 `$...$` 或 `$$...$$` 定界。
- 首次 AI 输出不符合科学符号契约时，先清理中文中的无语义英文冠词噪声，再携带字段、原因和违规片段执行最多三轮增量修复；无进展时升级为问题字段等义重写，最终仍不合规则拒绝进入会话和下载文件。
- 内容响应携带规范版本；前端拒绝缺少当前版本的旧会话，避免历史裸公式继续展示。
- PDF 使用浏览器已完成的 KaTeX 排版，但只按逻辑块整体分页，页尾放不下时整块移到下一页，不允许像素切割。
- Word 使用原生可编辑段落、列表和 OMML 数学节点；LaTeX 经 KaTeX 转为 MathML 后再映射到 Word 数学结构，不把整页报告作为图片。

## 视觉命题

像一张严谨的纸面解题单：高对比黑白骨架、低饱和墨蓝进度、淡黄色当前任务，长时间阅读不刺眼且保持课堂秩序感。

## 内容计划

- 左侧输入区：产品名、自动识别选项、题目上传和主操作，不显示任何 AI 配置信息。
- 右侧工作区：题目摘要、四步路径、第 5 个完整答案模块与报告下载操作。
- 配置页：返回主工具、服务状态、接口配置、连接测试与保存反馈。

## 交互命题

- 生成成功后默认展开第一步，前四步和第 5 个完整答案模块均可切换展开。
- 用户点击任意步骤即可展开对应 AI 指导，切换使用快速高度与透明度过渡。
- 上传区在拖入文件时改变边框和背景；生成按钮提供明确的加载和错误状态。

## 高层实施计划

1. 建立 React + Vite 前端与 Express 服务端。
2. 实现文件解析、AI 兼容客户端、加密配置和只读结果会话。
3. 实现主工作台、AI 配置页和响应式样式。
4. 补充单元测试、构建检查、接口冒烟测试和 Playwright 双端验收。
5. 建立跨学科 LaTeX 校验、噪声预清理、最多三轮增量修复、网页科学文本渲染与 PDF/Word 同源分页导出。

## 验证

- 单元测试覆盖配置加密、AI JSON 解析、四步指导结构和只读会话恢复。
- `npm run lint`、`npm test`、`npm run build` 均在 60 秒内完成。
- 健康检查、配置状态、未授权配置请求和无配置分析请求返回预期状态码。
- 对抗测试覆盖数学、物理、化学、生物、地理的规范表达，以及错误 LaTeX、乱码和裸 Unicode 符号的拒绝路径。
- Playwright 在 1536×1024 与 390×844 视口验证无溢出、无重叠、用户端无模型信息且下载按钮仅在生成后出现。
- 下载真实 PDF 与 DOCX，校验文件头；PDF 渲染为图片检查无跨页切割，DOCX 验证无整页媒体图、正文可提取且包含 OMML 数学节点。

## 回滚

项目为新建应用，无存量数据迁移。回滚时停止服务并恢复上一个可用构建；AI 配置位于 `.data/`，删除构建产物不会影响本地配置。若导出依赖导致浏览器兼容问题，可回退导出组件与对应依赖，不影响分析 API 和既有只读会话。
