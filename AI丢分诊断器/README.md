# 孩子丢分CT诊断

一个单页面、单功能的 AI 丢分诊断网站。用户填写年级、科目、考试类型并批量上传试卷、作业、错题或批注资料后，后端会抽取文件内容并调用 AI 接口生成结构化诊断报告。

## 功能

- 支持多文件上传，文件数量不设上限。
- 单个文件大小限制为 50MB。
- 支持 PDF、DOC、DOCX、PNG、JPG。
- PDF/DOCX 会抽取正文，图片会作为视觉输入交给 AI。
- 完整报告包含数据诊断总览、资料可信度、失分归因权重、优先级矩阵、能力基准差距、证据链矩阵、学情画像、根因链路、题型诊断、知识模块热区、风险预测、补救 ROI、复测观察指标、老师跟进和诊断可信度。

## 本地运行

```bash
npm install
npm start
```

打开浏览器访问：

```text
http://localhost:3000
```

## 配置

接口配置放在 `.env` 中：

```env
AI_BASE_URL=https://cccapi.top/v1
AI_MODEL=gemini-3.5-flash
CCC_API_KEY=你的接口密钥
PORT=3000
```

前端不会直接读取密钥，所有 AI 请求都会通过 `server.js` 代理。
