# 图形选项组识别与展示计划

## 问题陈述和动机

部分选择题的 A、B、C、D 选项完全由几何图案、实验装置、地图局部或其他图片构成。当前识别结果可能同时返回四个空 Markdown 图片链接和一张包含全部选项的题图，网页因而显示 `Blank Equation`、空白选项框和重复题图。图形选项的真实语义依赖选项标签与图片的空间对应关系，不能把空图片 URL 当作普通文本选项渲染。

## 范围

- 将每个视觉选项定义为独立的 `option` 图形，并通过 `optionLabel` 关联 A/B/C/D 等选项标签。
- 网页和 Word 均按“选项标签 + 对应图片”展示四个选项，不能只显示一张合并题图。
- `option-group` 仅作为旧识别结果或复检失败时的兼容回退，同时恢复 A/B/C/D 文本选项标签。
- 当有效独立选项图存在时，将空 Markdown 图片、`Blank Equation` 等占位内容规范为选项标签，不重复渲染失败文本。
- 首次识别只有图片占位或合并选项图、没有独立选项图时，自动执行一次选项边界复检。
- 复用现有题图裁切、实时预览、手动微调和 Word 图片导出能力。
- 混合型选项中有意义的文字或公式选项必须保留。

## 非目标

- 不对选项图进行图像内容分类或自动作答。
- 不依赖等宽切割把合并选项图机械拆成四份；独立边界由视觉模型识别，避免 1×4、2×2 等布局误切。
- 不在缺少有效选项组边界时静默删除原始选项数据。
- 不改变纯文字、纯公式和普通图文混合题的既有布局。

## 设计边界和约束

- `option` 边界只覆盖对应选项图片内容，标签由 `optionLabel` 结构化保存并由界面统一绘制。
- 同一道题的独立选项图必须具有唯一、可排序的标签；没有标签的选项图不能覆盖已有选项数据。
- `option-group` 边界必须包含全部选项标签和图案，但不得包含题干或下一道题。
- 视觉占位内容必须转换为 A/B/C/D 标签，而不是从选项数组中完全删除。
- 过滤逻辑只替换纯图片 Markdown、空标签、`Blank Equation` 等占位内容，不删除有意义文字。
- 历史模型未返回 `kind` 时，可根据“图形选项、图片选项、四个图案选项”等说明推断类型。
- 图形选项组在网页和 Word 中均使用同一裁切图片，避免两端结果不一致。

## 高层实施计划

1. 扩展题图类型为 `diagram | table | option-group | option`，增加 `optionLabel`。
2. 在共享层实现视觉占位检测、标签提取和选项标签恢复。
3. 服务端优先规范化独立选项图；只有合并图或占位选项时执行一次独立边界复检。
4. 网页以两列选项卡展示“标签 + 图片”，合并图回退时显示标签网格和完整图片。
5. Word 以两列表格写入四个视觉选项，每个单元格保留标签和对应图片。
6. 增加识别兼容、恢复失败、混合选项、Word 结构和浏览器页面回归。

## 验证

- 四个空 Codecogs/Markdown 图片选项被恢复为 A/B/C/D 选项结构，不再渲染失败内容。
- 独立边界可用时，网页和 Word 均显示四个“标签 + 图片”选项。
- 每个图形选项可单独打开裁切微调，实时预览正常。
- 只有合并图时，仍显示 A/B/C/D 标签和完整选项组图片。
- 缺少任何有效边界时保留原选项并返回警告。
- 混合选项中的真实文字和公式不被误删。
- 类型检查、冒烟测试、专项回归和生产构建通过。

## 回滚

该变更不涉及数据迁移。回退类型扩展和占位过滤后，历史题图仍按普通 `diagram` 显示，原选项数组保持兼容。
