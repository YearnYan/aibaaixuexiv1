# 题卷重排识别与增量输出计划

## 本次卡顿修复补充

- 为单次上游 AI 请求设置 180 秒默认上限，为单个识别批次设置 600 秒总上限。
- 批次超时后递归拆分页面；单页重试仍无法响应时返回失败并退款，不生成占位成功项。
- 不改变其他子网站、积分结算接口或已完成批次的断点语义。

## 问题陈述和动机

旧链路在整份资料识别结束后才展示结果，上传阶段和识别阶段在界面上混为一谈；大文件失败重连时用户还会误以为从第一页重新识别。计费也按整份请求预扣，无法表达“只有已经进入 A4 预览的页才算成功”。

生产 116 页会话进一步证明：后台已完成全部页面并生成 310 个内容项，但单次计费 POST 长时间无响应，浏览器或网关先断开；前端又把 `USAGE_REQUEST_IN_PROGRESS` 当成终态，导致用户看不到已经完成的结果。长任务必须与单次 HTTP 连接解耦，同时保持“失败退款、成功只扣一次”的积分不变量。

## 范围

- 仅修改“题卷重排WORD”子网站的识别编排、会话断点和回归测试。
- 上传后的 PDF/图片页面进入可选的全屏预览，页面默认全选并显示稳定序号。
- 智能识别按最多 5 个选中页面组成一个用户不可见的批次；每个批次完成即把结果追加到 A4 预览。
- 每个成功批次独立结算，失败批次使用既有非 2xx 退款契约。
- 混合 DOCX 资料的 Word 页数只在首批计入，后续批次不重复结算。
- 主识别、各类复检分别提交阶段断点。
- 结构失败按批次到单页自适应缩小；单页仍失败时返回非 2xx，由前端保留该上传页供重试。
- 复检按单目标和相关页面执行；复检结构失败使用原页保真图替代，不重复主识别。
- 完成请求采用有界长轮询；窗口结束只释放 HTTP 请求，同一后台会话继续执行。
- 浏览器自动处理处理中、已结算和网络断线状态，不向用户展示平台幂等冲突。
- 结果交付使用会话级互斥锁，只有一个计费请求能够成功交付结果。

## 非目标

- 不修改其他子网站、统一平台积分规则或 AI 路由配置。
- 不承诺在 AI 上游完全不可用时生成可编辑文字；上游传输故障仍按现有退款契约处理。
- 不改变现有 HTTP 端点和浏览器上传协议。

## 设计边界和约束

- 成功结果必须覆盖全部上传页，且不得采用未通过结构校验的模型输出。
- 正常文件不能增加额外模型调用；只有检测到结构问题时才局部降载或复检。
- 已成功的批次、主识别阶段和复检阶段不得重复调用。
- 主识别只有覆盖全部输入页的可编辑结果才能成功结算；原页占位不得进入 A4 预览。
- 会话替换任一上传页后，既有阶段断点全部失效。
- 单次完成请求最长等待 45 秒；未完成返回 409，使该次预扣自动退款，再用新幂等键接入。
- 状态接口只有在结果已完整送达一个成功计费响应后才返回结果正文。
- 响应中断必须释放结果交付权；并发请求不得重复获得成功响应。
- 页面选择只影响 PDF/图片识别；DOCX 已解析内容继续完整保留。
- 批次内部把页面编号暂时归一化为 0...N-1，结果交付前映射回原始页码，裁图必须引用原始页面。
- 用户可在识别批次运行期间导出当前已经进入 A4 预览的内容。

## 高层实施计划

1. 扩展会话断点，记录批次主结果和已完成复检种类。
2. 将复检改为单目标、相关页、有限结构重试。
3. 将所有结构类失败纳入自适应拆分，单页最终失败走退款与失败页重试。
4. 增加 116 页、单坏页、复检失败和跨请求阶段恢复测试。
5. 前端把选中页面分成最多 5 页一批，批次成功后立即追加 A4 结果。
6. 完成子站、平台、构建和生产故障注入验证后部署。
7. 增加有界完成请求、自动重连、交付互斥和断线结果回读，消除长连接对最终结果可达性的影响。

## 验证

- 116 页正常资料必须完整覆盖；坏页耗尽重试时不得返回占位成功结果。
- 主识别成功、复检上游失败后重新接入时，主识别调用次数保持为 1。
- 复检连续返回坏结构时，任务成功并以完整原页图保留目标内容。
- 正常 61 页基线调用次数不增加。
- 题卷子站全量测试、TypeScript、平台全量测试和生产构建通过。
- 完成请求超过窗口返回 `session_processing`，后台调用次数保持不变，后续请求取得同一结果。
- `USAGE_REQUEST_IN_PROGRESS`、`USAGE_REQUEST_ALREADY_SETTLED` 和网络断线均自动恢复。
- 结果交付前状态接口不泄露正文；交付成功后支持断线回读；并发请求最多一个成功。
- 1、5、6、11 页选中资料分别产生 1、1、2、3 个最多 5 页批次；批次失败时对应请求自动退款。
